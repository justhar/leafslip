## Expected Usage Patterns

Typical active MSME user:
- 5 chat messages daily (assistant usage)
- 1–2 receipt scans (OCR)
- 1–2 product lookups (insights)
- 1 dashboard load (stats)

Spike days:
- 20 chat messages (high interaction)
- 5 receipts (batch upload)
- Proportional insights + dashboard

## Pricing Model

Gemini-2.5-flash (as of May 2026):
- Input: $0.075 per 1M tokens
- Output: $0.30 per 1M tokens
- Cost per token: ~$0.0000001 input, ~$0.0000003 output (averaged 2:1 I/O ratio)

Cost formula per call:
```
costUSD = (inputTokens * 0.000075/1M + outputTokens * 0.30/1M)
        = (inputTokens * 0.000000075 + outputTokens * 0.0000003)
```
