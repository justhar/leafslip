## Current AI Integration Points

From codebase analysis:

1. **Chat Advisor** (`app/actions/chat.ts`)
   - Model: `gemini-2.5-flash` via `generateText()`
   - Input: 30-day sales context + max 10 messages
   - Caching: None (each message is fresh call)
   - Tokens/call: 1200–1800 estimated

2. **Receipt OCR** (`app/actions/receipts.ts`)
   - Model: `gemini-2.5-flash` via `generateObject()`
   - Input: Base64 image + extraction schema
   - Caching: SHA256 in-memory (24h TTL)
   - Tokens/call: 1500–2200 estimated

3. **Product Insights** (`app/actions/products.ts`)
   - Model: `gemini-2.5-flash` via `generateObject()`
   - Input: Product name + 30d history + stock
   - Caching: DB cache in `ai_insights` (24h minimum age)
   - Tokens/call: 800–1200 estimated

4. **Dashboard Insights** (`app/actions/dashboard.ts`)
   - Model: `gemini-2.5-flash` via `generateText()`
   - Input: Dashboard stats + context
   - Caching: None
   - Tokens/call: 1200–1500 estimated

**Aggregate:** 11,550-35,000 tokens/user/day baseline to spike (per RESEARCH.md audit).

## Tech Stack
- Drizzle ORM + PostgreSQL (Neon)
- `@ai-sdk/google@^2.0.52` (Vercel AI SDK)
- Zod for validation
- TypeScript
- Next.js 16 (App Router)

## Design Principles

From RESEARCH.md Architectural Responsibility Map:
- **Token Tracking & Instrumentation**: Server-side (in actions) + logging to DB table
- **Caching Layer**: Database for multi-session persistence + browser localStorage for client state
